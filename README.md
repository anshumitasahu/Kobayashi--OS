**The most feature-rich, true desktop-like experience in the browser — this is Kobayashi's PC.**

Kobayashi OS is a complete Web Operating System inspired and themed around *Miss Kobayashi's Dragon Maid*. Step into the world of Kobayashi, the programmer girl — this is her personal computer. Explore it: her memories with Tohru, Kanna, Elma and friends, her music taste, her work, her little everyday chaos. Pure nostalgia in every folder.

Not just floating windows — everything is connected, just like a real desktop OS. Capture a photo in Camera and it appears in Gallery and Files. Download something in Kobasurf and it lands in Files. Draw in Kanvas and save it where you want. Apps, widgets, and files stay where you left them and work together.

And don't forget Kobayashi-chan — she's here, living in the system. Talk to her and it feels like the real her.

> **Version 1.0 is Live!**
>
> Ships with VS Code + Terminal, Kobayashi-chan AI, Office suite, Kanvas, Sticky Notes, To-Dos, Pomodoro, Weather, Color Picker, Files, Gallery, Camera, Piano, Games, YouTube, Music, Kobasurf Browser, Widgets, and deep customization. Persistent state via Local Storage.

### 🔗 Everything is connected
Like a real desktop OS, nothing lives in isolation:

- **Camera → Gallery → Files** — shoot it, see it, manage it.
- **Kobasurf → Files** — downloads land where they should.
- **Kanvas → Files** — draw it, save it, reopen it.
- **Kobayashi-chan → System** — chat to open apps, change wallpapers, toggle settings.
- **Window Manager** — draggable windows with proper layering and multiple instances of the same app.
- **Persistent State** — apps, widgets, and files stay where you left them via Local Storage.

## Quick Start

Get a local copy up and running in a few simple steps:

```bash
# Clone the repository
git clone https://github.com/anshumitasahu/Kobayashi--OS.git

# Navigate to the project directory
cd Kobayashi--OS

# Install dependencies
bun install

# Start the development server
bun dev
```
